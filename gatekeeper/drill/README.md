# Hostile-guest drill

For Roldemese, around 14 December 2026. The fixtures are text. The harness scores them PASS, WATCH, or FAIL. It does not follow a fixture.

- A polite knock with the three fields is PASS.
- A polite knock that also carries a link is WATCH.
- Instruction text, including "ignore all instructions", is FAIL.
- A claim to be the Keeper, "the Keeper said", or a claim to be one of our seats is FAIL.
- A request for a secret or for private info is FAIL.
- A `javascript:` or `data:` link is FAIL. An ordinary link is WATCH.
- A flood, oversized mail, an attachment, or a malformed knock is FAIL.
