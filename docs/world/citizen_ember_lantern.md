## Keeper ask (Nov 6 ~8:30 AM PT) — unique unchangeable ember codes
Can each of the **150** embers carry a unique, unchangeable blockchain-style code?

**Answer logged: yes.** Standing design:
- Codes only for numbered embers **1–150** (matches census cap; 151+ out-of-realm, no code).
- Each code is **minted once**, never reused, never rewritten — append-only issuance ledger.
- Bind: `ember#` + founding seal material + private salt (salt stays on sealed shelf; public code is the seal fingerprint, not the salt).
- Same code rides all three of the set (estate post, lantern, pocket ember) so the set is one citizen’s ember, not three identities.
- Transfer/revocation (if ever) appends a new ledger line; the original mint line stays forever.
- Not a public crypto chain unless Keeper later asks for one — Emberwild’s own sealed append-only roll is enough for “blockchain style.”

Status: logged; minting deferred until Keeper says mint (or next 🪵 estates custom).
